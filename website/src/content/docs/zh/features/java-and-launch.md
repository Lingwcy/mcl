## Java 管理

前往 **设置 → Java** 可管理本机运行环境：

- **本机探测** — 扫描常见安装目录并探测二进制文件，读取准确的主版本号、发行商、架构与编译器存在状态。
- **Eclipse Temurin 下载** — 从官方通道下载固定 SHA-256 与大小的 Temurin JDK/JRE，并发布到应用数据目录下的受管 `java` 目录。
- **启动自动匹配** — 启动实例时，优先匹配兼容的显式偏好或本机补丁版本；若缺少匹配环境，将自动安装对应主版本与架构的 Temurin 后继续启动。

## 自动内存分配

所有实例在后台启动准备阶段自动计算安全内存上限：

- **64 位 Java**：按物理内存的四分之一计算，并限制在 `2048 MiB` 至 `6144 MiB` 之间。
- **32 位 Java**：固定为 `1024 MiB`。
- **兜底值**：无法探测物理内存时使用保守的 `2048 MiB`。

## 游戏设置与 GC 策略

在 **设置 → 游戏** 中可配置五种内置 GC 策略（包含对 Java 23+ ZGC 参数的自动兼容处理）以及经过安全校验的自定义 JVM 参数，修改后自动在后台串行保存。

## 启动工作区

点击 **启动** 后会进入独立启动准备页，实时呈现资源校验、Java 解析、会话交接、窗口观测状态，并支持一键停止或查看脱敏后的本次会话日志。
