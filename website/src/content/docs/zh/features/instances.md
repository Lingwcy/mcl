`mcl` 中的每个实例都拥有独立的配置、资源、存档与占用锁状态，避免不同版本的模组与加载器相互冲突。

## 实例设置

在实例详情页中，你可以调整：

- **名称与图标** — 选择内置像素风预设图标，或导入本地图片（后台自动缩放并归一化保存至实例目录，不保留原始路径引用）。
- **游戏位置** — 保存在启动器默认位置，或关联到自定义的外部游戏目录。
- **Java 与启动偏好** — 按实例覆盖偏好 Java 版本或启动参数。

## 发现已有游戏

通过 **发现已有游戏** 功能，可以扫描其他启动器的 `.minecraft` 目录或 Swift Craft Launcher（`sjmcl`）的 `profiles` 实例（含 Fabric、Quilt、Forge、NeoForge 声明）。确认后会复制为 `mcl` 受管实例，原目录保持不变。

## 迁移游戏目录

实例支持在内置目录与外部游戏目录之间迁移。迁移过程记录中断恢复状态，旧副本会保留直至你手动确认清理。
